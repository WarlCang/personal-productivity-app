TORRAS Productivity — Installation / 安装说明
=============================================

File to install / 安装文件: TORRAS Productivity-0.2.0-arm64.pkg
Requires / 要求: Mac with Apple Silicon (M1 or newer) / 苹果芯片的 Mac（M1 及以上）

The app is built in-house and not registered with Apple, so macOS shows a
security warning ONCE during installation. This is expected — follow either
method below. After installing, the app opens normally like any other app.

本应用为内部自建工具，未在 Apple 注册，因此安装时 macOS 会显示一次安全提示。
这是正常现象，按以下任一方法安装即可。安装完成后即可像普通应用一样使用。

------------------------------------------------------------
Method 1 — Normal install / 方法一：常规安装
------------------------------------------------------------
1. Double-click the .pkg file. If macOS warns that it "could not verify
   the app is free of malware", click "Done".
   双击 .pkg 文件。如果 macOS 提示"无法验证是否包含恶意软件"，点击"完成"。

2. Open  System Settings → Privacy & Security , scroll to the bottom.
   打开 系统设置 → 隐私与安全性 ，滚动到底部。

3. Find the line about "TORRAS Productivity...pkg" being blocked and click
   "Open Anyway", then confirm.
   找到关于该安装包被阻止的提示，点击"仍要打开"，然后确认。

4. The installer reopens — click Continue → Install and enter your Mac
   password. Done: the app is in the Applications folder.
   安装器重新打开 — 点击 继续 → 安装 并输入开机密码。完成后应用位于
   "应用程序"文件夹中。

------------------------------------------------------------
Method 2 — One Terminal command / 方法二：一条终端命令
------------------------------------------------------------
Open Terminal (Spotlight: search "Terminal") and run:
打开"终端"（聚焦搜索 Terminal）并执行：

  sudo installer -pkg ~/Downloads/"TORRAS Productivity-0.2.0-arm64.pkg" -target /

Enter your Mac password when asked (typing is invisible — that's normal).
The app installs straight into Applications with no security prompt.
按提示输入开机密码（输入时不显示，属正常）。应用将直接安装到"应用程序"，
不会出现安全提示。

------------------------------------------------------------
After installing / 安装完成后
------------------------------------------------------------
Find "TORRAS Productivity" in the Applications folder or via Spotlight.
All data is stored locally on your own Mac. Language can be switched
(中文/EN) at the bottom of the sidebar.
在"应用程序"文件夹或聚焦搜索中找到 TORRAS Productivity。所有数据仅保存在
你自己的电脑上。可在侧边栏底部切换语言（中文/EN）。
